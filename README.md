# Textile — Next-Gen Sustainable Agro-Biomass Materials Platform

A modern, high-performance web platform built with React, Vite, Tailwind CSS, Framer Motion, and GSAP showcasing sustainable, circular textile materials crafted from agricultural residue and biomass.

## 🚀 Features

- **Interactive Showcases & 3D Interactive Elements**: Seamlessly explore fibres, yarns, fabrics, and applications.
- **Eco-Metrics & Impact Calculator**: Real-time comparison metrics illustrating water savings, CO2 reduction, and land optimization.
- **Fluid Micro-Animations**: Powered by GSAP, Framer Motion, and Lenis smooth scrolling.
- **Commercial Sample & Swatch Requests**: Built-in modal flows for B2B buyer inquiries and sample kits.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewing.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) & Vanilla CSS
- **Animations**: [GSAP](https://greensock.com/gsap/), [Framer Motion](https://www.framer.com/motion/), [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```

### 4. Preview production build locally
```bash
npm run preview
```
